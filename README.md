# 플레이데이터 주간회고(WIL) 자동화

공부 메모를 붙여넣으면 AI가 플레이데이터 WIL 가이드(Four Fs + KPT + 트러블슈팅)에 맞춰
회고를 작성하고, Markdown/HTML로 변환한 뒤, 버튼 하나로 티스토리에 업로드까지 해주는
Tkinter 데스크톱 앱입니다.

## 주요 기능

- **AI 회고 생성**: 공부 메모 → Four Fs/KPT 기반 회고 Markdown, 일기체(~했다/~였다) 문체 고정
- **성찰 질문**: 고정 질문 5개(일반 주간) / 프로젝트 전용 질문 5개(프로젝트 주간) — 객관식 빠른 선택지 + 직접 입력(직접 입력이 항상 우선)
- **이해도 확인 퀴즈**: 첨부한 `.py`/`.ipynb` 코드 기반으로 AI가 객관식+서술형 질문을 만들어, 답변으로 공부 메모 초안까지 자동 작성
- **코드 인용 트러블슈팅**: 첨부 코드 파일에서 관련 부분을 그대로 발췌해 본문에 인용 (지어내지 않음)
- **프로젝트 주간 전용 처리**: 내 역할 / GitHub 링크 / README 기반 산출물 소개 / 산출물 이미지 자동 본문 삽입 / 대표이미지·카테고리 자동 적용
- **프로젝트 + 수업 내용 자연 합성** (선택 사항): 프로젝트 주간에 별도 수업 내용도 있었다면, 체크박스 하나로 "프로젝트 회고 생성 → 수업 회고 생성 → 하나로 합치기" 3단계를 거쳐 자연스러운 글 하나로 통합
- **월간 종합 회고**: 한 달치 주간회고 링크/요약을 모아 종합 회고 자동 생성
- **티스토리 자동 업로드**: Playwright로 실제 브라우저를 조작, 기본 공개 범위는 항상 비공개
- **초기 설정 도우미**: 다른 캠프생도 바로 쓸 수 있도록 API 키/캠프 정보/티스토리 로그인을 단계별로 안내

## 1. 설치

```bash
cd wil_blog_automation
python -m pip install -r requirements.txt
```

티스토리 업로드 자동화는 Playwright 번들 Chromium이 아니라 **Windows에 기본 설치된
Microsoft Edge**를 직접 띄워서 사용합니다(`channel="msedge"`). 별도로 브라우저를
내려받을 필요가 없고, Edge만 설치되어 있으면 됩니다(Windows 10/11이면 기본 내장).

## 2. 실행

평소에는 바탕화면의 **"주간회고 자동화"** 바로가기를 더블클릭하면 됩니다.
(이 바로가기는 `주간회고_실행.bat`을 가리키며, 처음 설치할 때 한 번만 만들어두면 됩니다.)

터미널에서 직접 실행하려면:

```bash
python main.py
```

## 3. 최초 설정

처음 실행하면 **초기 설정 도우미**가 자동으로 뜨면서 Gemini API 키 → 캠프 정보 → 티스토리
로그인 → (선택) 대표이미지/카테고리 순서로 안내해줍니다. 나중에 다시 열려면 앱 메뉴
`설정 > 초기 설정 도우미`를 누르면 됩니다. 아래는 각 항목을 수동으로 설정하고 싶을 때
(`설정 > API / 티스토리 설정`) 참고용 설명입니다.

### 3-1. Gemini API 키
1. https://aistudio.google.com/apikey 에서 API 키를 발급받습니다. (무료 등급 제공)
2. 설정 창의 "API 키" 칸에 붙여넣고 저장합니다.

### 3-2. 티스토리 자동 업로드 (선택, 안 하면 Markdown/HTML 저장까지만 가능)

티스토리 Open API는 2024년 2월 서비스가 완전히 종료되었고, 로그인도 카카오계정 전용이라
API 키/토큰 방식은 더 이상 쓸 수 없습니다. 대신 이 앱은 **Playwright로 실제 브라우저를 띄워
티스토리 글쓰기 화면을 직접 조작**합니다.

1. 설정 창의 "블로그 이름"에 `내아이디.tistory.com`에서 `내아이디` 부분만 입력하고 저장합니다.
2. "티스토리 로그인 / 세션 갱신" 버튼을 누르면 브라우저 창이 뜹니다. **그 창에서 직접**
   카카오계정으로 로그인합니다 (비밀번호/2단계 인증을 앱이 아닌 실제 브라우저 화면에 본인이
   입력 — 어떤 자동입력도 하지 않습니다).
3. 로그인에 성공하면 세션 쿠키가 `tistory_session.json`에 저장되어, 다음부터는 로그인 없이
   바로 업로드를 시도합니다. (세션이 만료되면 같은 버튼으로 다시 로그인하면 됩니다)

## 4. 사용 순서

1. 왼쪽 텍스트창에 이번 주 공부 메모를 자유 형식으로 입력합니다. (또는 "파일에서 불러오기"로 txt/md 불러오기)
2. **① AI 회고 생성** 버튼을 누르면 오른쪽에 Markdown 미리보기, HTML, 제목/태그 추천, 성장 인사이트가 채워집니다.
3. 마음에 안 들면 **다시 생성**으로 다른 버전을 받아보거나, 미리보기 창에서 직접 수정합니다.
4. "제목 추천 / 태그" 탭에서 제목 후보를 더블클릭하면 게시 제목으로 반영됩니다.
5. **Markdown 저장** / **HTML 저장** / **복사**로 원하는 형태로 내보낼 수 있습니다.
6. 티스토리에 바로 올리려면 **② 티스토리 업로드**를 누르고, 공개 범위(기본값 비공개)를 확인한 뒤 게시합니다.

## 5. 업로드 동작 방식 (중요)

"② 티스토리 업로드"를 누르면:
1. (로그인 세션이 없거나 만료된 경우) 브라우저 창이 열리고, 로그인 대기 상태가 됩니다 →
   그 창에서 직접 카카오 로그인을 완료합니다.
2. 제목 / 본문(HTML 모드) / 태그를 자동으로 입력합니다.
3. '완료 → 공개범위 선택 → 발행' 버튼까지 자동 클릭을 시도합니다.
4. 티스토리 에디터 구조가 바뀌어 자동 클릭이 실패하면, **억지로 아무 버튼이나 누르지 않고**
   열려있는 브라우저 창에서 사용자가 직접 완료 버튼을 누르도록 안내한 뒤 그 결과(URL 변경)를
   감지해서 마무리합니다.

기본 공개 범위는 항상 **비공개**이며, 공개로 올리려면 업로드 확인창에서 "공개 발행"을 직접
선택해야 합니다. 브라우저 자동화 특성상 티스토리가 에디터 UI를 바꾸면 선택자가 깨질 수 있는데,
그 경우에도 실수로 잘못 게시되지 않도록 자동 클릭 실패 시 항상 사람 확인으로 넘어가게 설계했습니다.
만약 업로드가 실패한다면 어느 단계에서 멈췄는지(에러 메시지, 브라우저 화면) 알려주시면 선택자를
같이 고칠 수 있습니다.

## 6. 성장 인사이트

회고를 생성할 때마다 `history.json`에 날짜/태그/한줄요약이 누적 저장됩니다. "성장 인사이트" 탭에서
최근까지 가장 많이 다룬 기술, 지난주 대비 새로 등장한 기술, 최근 회고 요약을 확인할 수 있습니다.

## 7. 프로젝트 주간 전용 기능

회차가 커리큘럼상 프로젝트 주간(단위/최종 프로젝트)이면 "프로젝트 정보" 탭과 "성찰 질문" 탭이
자동으로 바뀝니다.

- **내 역할**: 이번 프로젝트에서 맡은 역할을 적어두면, AI가 "내가 맡은 역할과 기여" 섹션을
  지어내지 않고 이 내용을 그대로 근거로 작성합니다.
- **GitHub 저장소 / 산출물 소개(README) / 산출물 이미지**: 입력해두면 "🚀 프로젝트 산출물 소개"
  섹션에 포트폴리오처럼 소개되고, 이미지는 본문에 자동 삽입됩니다.
- **프로젝트 전용 성찰 질문**: 일반 주간의 성찰 질문 5개 대신, 역할 자기평가 / 새로 이해한 기술 /
  협업 어려움 / 아쉬운 점 / 다음 프로젝트 목표를 묻는 질문 5개로 자동 전환됩니다.
- **이번 주 수업 내용 포함 (선택 사항)**: 프로젝트 주간에 별도 수업도 진행됐다면 체크박스를 켜고
  수업 내용을 적습니다. 켜져 있으면 생성 시 다음 3단계를 거칩니다:
  1. 프로젝트 회고 초안 생성
  2. 수업 내용 회고 초안 생성 (일반 주간과 같은 방식)
  3. 두 초안을 AI가 다시 읽고, 섹션을 나열하지 않고 하나의 자연스러운 글로 재구성(합치기)

  체크박스를 꺼두면 기존처럼 프로젝트 회고만 단일 호출로 생성됩니다(필수 아님, 완전 선택 사항).

## 8. 월간 종합 회고 (앱 메뉴 `월간 회고 > 월간 종합 회고 만들기`)

한 달 동안 발행한 주간회고들을 `history.json`에서 모아 각 글의 링크와 함께 종합하고, 월간
성찰 질문(객관식 빠른 선택지 + 직접 입력)을 거쳐 월간 종합회고 글을 생성/업로드합니다.
제목은 `[캠프명] N기 M월종합회고록` 형식으로 자동 조립됩니다.

## 파일 구성

- `main.py` – Tkinter GUI 및 전체 흐름 제어
- `ai_generator.py` – Gemini API 호출, WIL 가이드 기반 프롬프트, JSON 파싱, 프로젝트+수업 합치기
- `tistory_browser.py` – Playwright로 티스토리 로그인/글쓰기 화면을 직접 조작하는 브라우저 자동화
- `markdown_utils.py` – Markdown 조립 / HTML 변환 / 파일 저장
- `storage.py` – `config.json`(설정), `history.json`(회고 이력) 로드/저장 (손상된 파일은 자동 백업 후 기본값 복구)
- `curriculum.py` – SK네트웍스 35기 커리큘럼 일정, 회차/프로젝트 주간 자동 계산
- `code_files.py` – 첨부한 `.py`/`.ipynb`에서 AI 프롬프트용 코드 컨텍스트 추출
- `monthly_dialog.py` – 월간 종합 회고 전용 창
- `setup_wizard.py` – 초기 설정 도우미 (다른 캠프생도 쓸 수 있도록 온보딩)
- `config.example.json` – 설정 파일 예시 템플릿 (실제 `config.json`은 git에 미포함)
- `tistory_session.json` – 티스토리 로그인 세션(쿠키) 저장 파일, 최초 실행 후 자동 생성 (git에는 미포함)
- `output/` – 저장한 Markdown/HTML 파일이 쌓이는 폴더 (git에는 미포함)

## 개발 이력 / 변경 사항

처음 "공부 메모 → AI 회고 → 업로드"라는 단순한 흐름에서 시작해서, 실제로 매주 써보면서
아래 순서로 기능을 넓혀왔습니다.

1. **기본 파이프라인**: 공부 메모 → Gemini 구조화 출력(JSON Schema)으로 WIL 가이드(Four Fs/KPT)
   기반 회고 생성 → Markdown/HTML 미리보기 → Playwright로 티스토리 업로드까지 한 번에 처리.
2. **문체 고정**: "~습니다" 정중체 대신 일기체(~했다/~였다)로 통일, 우수 회고 사례를 분석해
   "문제 → 원인 → 해결 → 배운 점" 흐름과 감정/생각을 함께 녹이도록 프롬프트 보강.
3. **성찰 질문 + 이해도 확인 퀴즈**: 수동으로 다 타이핑하지 않아도 되도록, 성찰 질문 5개에
   객관식 빠른 선택지(직접 입력이 항상 우선)를 추가하고, 첨부한 코드 파일 기반으로 AI가
   이해도 확인 퀴즈를 만들어 답변으로 공부 메모 초안까지 자동 작성하도록 확장.
4. **커리큘럼 자동화**: SK네트웍스 35기 전체 일정을 반영해 회차 번호와 프로젝트 주간 여부를
   날짜 기준으로 자동 계산 (`[캠프명] N기 M회차 회고` 형식으로 제목 자동 조립).
5. **프로젝트 주간 전용 처리**: GitHub 링크/README/산출물 이미지를 입력하면 포트폴리오처럼
   소개하는 전용 섹션 구조로 전환, 대표이미지·카테고리 자동 적용.
6. **월간 종합 회고**: 한 달치 주간회고 링크를 모아 성장 흐름을 짚어주는 종합회고 생성 기능 추가.
7. **초기 설정 도우미**: 다른 캠프생에게 앱을 전달해도 바로 쓸 수 있도록, 이 프로젝트를 만들며
   겪었던 문제(모델별 무료 한도, `-latest` 별칭, 카카오 전용 로그인 등)를 그대로 안내 문구로
   담은 단계별 설정 마법사 추가.
8. **베타테스트로 발견/수정한 버그들**:
   - `config.json`/`history.json`이 손상돼 있으면 앱이 시작부터 죽던 문제 → 손상 파일은
     `.corrupted`로 백업하고 기본값으로 안전하게 폴백하도록 수정.
   - 업로드/생성 버튼을 빠르게 연타하면 확인창이 중복으로 뜨고, 최악의 경우 같은 글이 티스토리에
     **중복 게시**될 수 있던 문제 → 업로드·로그인·생성 버튼 전부에 중복 클릭 방지 가드 추가
     (`main.py`, `monthly_dialog.py`, `setup_wizard.py`).
   - 대문자 확장자(`.PY`) 코드 파일이 조용히 무시되던 문제 수정.
   - 티스토리 "공개(보호) 발행"처럼 버튼 문구가 바뀌는 경우 발행 버튼을 못 찾던 문제, 업로드 성공
     후 실제 게시 URL을 못 찾던 문제 수정.
9. **프로젝트 주간 세분화 (최신)**: 프로젝트 주간에서 "내 역할"을 직접 입력받아 AI가 지어내지
   않도록 하고, 프로젝트 전용 셀프체크 성찰 질문 5개를 추가. 프로젝트 주간에 별도 수업 내용도
   있었던 경우를 위해 "프로젝트 회고 생성 → 수업 회고 생성 → 자연스럽게 합치기" 3단계 파이프라인을
   선택 사항(체크박스)으로 추가 — 두 내용을 섹션으로 나열하지 않고 하나의 글로 재구성.
